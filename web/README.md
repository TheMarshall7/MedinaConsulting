# Medina Grant Writing & Consulting — Next.js site

## Develop

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
cd web
npm run build
npm start
```

## Stack

- Next.js App Router (static-friendly SSG pages)
- TypeScript + Tailwind CSS v4
- GSAP motion (client-only)
- SEO: metadata, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`

## Pages

- `/` — home
- `/services`
- `/about`
- `/faq`
- `/contact`

Logos live in `public/Medina.png` and `public/Medina-Logo.png`.
